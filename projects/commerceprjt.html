Project Details

E-commerce Data Engineering Pipeline

A beginner-level ETL pipeline that extracts customer, product and order data from MySQL, cleans it with Pandas, loads it back into MySQL and builds a final sales reporting table using SQL.

View on GitHub

1Problem Statement

E-commerce businesses keep customer, product and order information in separate datasets. Missing values, duplicate records and incorrect data types can make business reports inaccurate. The goal of this project was to build a basic ETL pipeline that extracts the data, performs data quality checks and transformations, and loads the cleaned data into MySQL for further analysis.

2Project Objectives

  • Work with multiple related datasets: customers, products and orders
  • Extract data from a MySQL database using Python
  • Inspect and clean the data using Pandas
  • Identify missing values and duplicate records
  • Convert columns into appropriate data types
  • Load the cleaned data back into MySQL
  • Use SQL JOINs and aggregate functions to combine and analyse the data
  • Create a final sales reporting table

3Approach & Solution

Connected Python to MySQL using SQLAlchemy and extracted the customers, products and orders tables into Pandas DataFrames. Inspected each dataset for missing values, duplicate records and incorrect data types, then cleaned and converted the columns. The cleaned data was loaded back into MySQL, where SQL JOINs and aggregate functions were used to combine the three tables into a final sales reporting table.

4Pipeline Flow

ETL pipelineExtract MySQL (customers, products, orders) → Pandas via SQLAlchemy Inspect missing values · duplicate records · data types Clean handle nulls · remove duplicates · convert dtypes Load cleaned tables → MySQL Transform SQL JOINs + aggregate functions Output final sales reporting table

5Tools & Technologies

Python – connects to the database and performs data processing.

Pandas – reads, inspects, cleans and transforms structured data.

MySQL – stores the original and cleaned customer, product and order data.

SQL – creates tables, joins tables, validates data and performs analysis.

SQLAlchemy – connection interface used by Pandas to communicate with MySQL.

Jupyter Notebook – development environment for writing and running the code.
